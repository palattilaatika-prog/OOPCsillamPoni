We can see inheritance in this project in the "RepuloCsilamPoni.java" where it extends the "CsillamPoni" class.
It inherits the "nev" and "csillamPont" attributes, and the methods of the "CsillamPoni" class.
We can also see polimorphism in the same class, since it overrides the "bemutatkozas()" method.
